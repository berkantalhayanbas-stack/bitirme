# Sürüş: hazır çevrim (PROF). Her senaryo bir stres uygular, ECU fark edip önlem alır.

=== D3 Sogutma arizasi
+1 m 0             ; Arac hazir surus cevrimini suruyor
+0 k 1             ; D3: sogutma arizasi (ECU'ya haber verilmedi)
bekle cause&2 700  ; ECU arizayi kendi kestiriminden buldu: izin %70 (>= 120 s; 25 C soguk pakette ~490 s)
+10 k 1            ; D3: sogutma onarildi
+0 !reset          ; (ECU yeniden baslatildi: alarm temizlendi)
bekle state==1 30  ; ECU NORMAL

=== A2 Asiri isinma
+2 k 2             ; A2: paket isinmaya basladi (0,5 C/s)
bekle state==3 90  ; ECU aciklanamayan isinmayi fark etti (termal anomali): LIMP-HOME, izin %25
bekle state==4 120 ; 60 C: SAFE-STOP, kontaktor acik, far sonuk
+3 k 2             ; A2: isi kaynagi kalkti, paket soguyor
bekle Ts<42 120    ; Paket sogudu (ikiz ortam + 2 °C'ye soğur; LM35 ~38 °C okuyor)
+0 !reset          ; Servis: ECU yeniden baslatildi
bekle state==1 30  ; ECU NORMAL

=== A3 Sensor koptu
+2 k 3             ; A3: sicaklik sensoru koptu
bekle state==3 5   ; ECU olcumun gecersiz oldugunu anladi: LIMP-HOME
+8 k 3             ; A3: sensor onarildi
+0 !reset
bekle state==1 30  ; ECU NORMAL

=== D4 Iletisim koptu
+2 k 4             ; D4: olcum hatti koptu
bekle state==4 3   ; ECU 0,5 s icinde SAFE
+8 k 4             ; D4: hat onarildi
+0 !reset
bekle state==1 30  ; ECU NORMAL

=== D5 Yazilim kilitlendi
+2 k 5             ; D5: ECU yazilimi kilitlendi (watchdog testi)
bekle state==4 5   ; Watchdog sifirladi, ECU SAFE'te acildi
+8 !reset
bekle state==1 30  ; ECU NORMAL
